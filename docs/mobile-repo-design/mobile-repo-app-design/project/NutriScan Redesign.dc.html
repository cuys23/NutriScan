Turn 1 · NutriScan redesign
Three directions for the app
Same data, same flows as the current build — 1,410 kcal logged across three meals. Each direction changes the posture: what the splash promises, what the home screen leads with, and how motion carries the user in. Every phone runs its splash automatically; press Replay to watch it again.
1a
Slow Kitchen
Paper and ink. Nutrition reads like a recipe card rather than a dashboard — serif numbers, ruled meal entries, no card shadows. The splash draws a bowl stroke by stroke and lets steam rise, so the first impression is food, not analytics.
